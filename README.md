# agent-desk

Claude Code와 OpenAI Codex에 코딩 작업을 보내고, 진행 상황과 구독 사용량을 한 화면에서 보는 Windows 데스크톱 앱입니다.

- 작업마다 Claude나 Codex를 직접 고르거나, 두 AI에게 의견을 물어 누가 맡을지 정할 수 있습니다
- 작업은 저장소를 건드리지 않는 별도 작업 폴더(git worktree)에서 실행되고, 결과를 확인한 뒤 직접 합칩니다
- 요금제(Claude Pro·Max, ChatGPT 무료·Plus 등)와 구독 사용률(%)을 보여 주고, 한도에 가까우면 작업을 막습니다
- 추가 요금이 생길 수 있는 상황에서는 앱이 진행하지 않고, 공식 도구를 직접 열어 관리하게 합니다

> agent-desk는 개인 프로젝트이며 Anthropic·OpenAI와 관계가 없습니다. 각 도구의 공식 기능을 대신하지 않고, 설치된 공식 CLI를 실행할 뿐입니다.

## 필요한 것

| 항목 | 설명 |
|---|---|
| Windows 10 / 11 (64비트) | 다른 OS는 지원하지 않습니다 |
| git | 작업 폴더(worktree)를 만들 때 씁니다 |
| [Claude Code](https://docs.claude.com/claude-code) | `claude` 명령이 PATH에 있고 로그인돼 있어야 합니다(Pro·Max 구독 또는 API 키) |
| [Codex](https://openai.com/codex) | Codex 앱 또는 `codex` CLI, 로그인 필요 |

둘 중 하나만 있어도 쓸 수 있습니다. 없는 쪽은 작업을 보낼 때 "설치돼 있지 않습니다"로 안내합니다.

## 설치

1. [Releases](../../releases)에서 `agent-desk-Setup-<버전>.exe`를 내려받습니다
2. 실행해서 설치 위치를 고르고 설치합니다. 바탕화면에 바로가기가 생깁니다
3. **"Windows의 PC 보호" 창이 뜨면** [추가 정보] → [실행]을 누릅니다. 설치 파일에 코드 서명이 없어서 뜨는 경고입니다. 받은 파일이 Releases에 적힌 SHA-256 값과 같은지 먼저 확인하세요

```powershell
Get-FileHash .\agent-desk-Setup-0.1.0.exe -Algorithm SHA256
```

## 사용 방법

### 작업 보내기

처음 실행하면 진행 현황 위에 **시작 전 점검**(Git·Claude Code·Codex 설치와 로그인)이 보입니다. 빠진 것이 있으면 설치·로그인 방법을 알려 줍니다.

1. 왼쪽 [새 작업]을 누릅니다
2. **저장소**: [찾기]로 작업할 git 저장소를 고릅니다. 마지막에 쓴 저장소를 기억합니다
3. **담당**: `두 AI에게 먼저 묻기` / `Claude` / `Codex` 중 고릅니다
   - 두 AI에게 먼저 묻기: 두 AI에게 읽기 전용으로 의견을 물은 뒤 담당과 계획을 보여 줍니다. [이대로 실행]을 눌러야 시작합니다. 의견을 묻는 데도 두 AI의 사용량이 조금씩 듭니다
4. **모델**: AI별로 고릅니다. `기본 설정`이면 각 도구의 설정값을 따릅니다. 모델 칸 아래에 같은 AI로 끝낸 최근 작업의 평균 시간과 사용량(API 환산값 또는 토큰)이 참고로 보입니다
5. **맡길 작업**에 지시를 적고 [보내기]

### 진행 보기

- 첫 화면 **진행 현황**은 실행 중인 작업마다 칸을 하나씩 나눠 보여 줍니다. 칸마다 진행 막대, 지금 하는 일, 걸린 시간(1초마다 갱신), 최근 기록(아래로 자동 스크롤)과 [중지]·[상세 보기] 버튼이 있습니다
- 창 너비에 따라 3열 → 2열 → 1열로 바뀌고, 아주 좁으면 왼쪽 목록이 접혀 [메뉴]로 엽니다. 10분 안에 끝난 작업은 흐리게 남아 있습니다
- Claude가 쓰는 글은 완성되기 전부터 한 글자씩 보입니다
- 새 작업 창의 "AI에게 진행 단계 표시 요청"을 켜 두면(기본 켬) AI가 `[진행 2/5] 단계 이름`처럼 알려 주는 단계로 % 막대를 보여 줍니다. **AI가 스스로 알려 주는 값**이라 정확하지 않을 수 있고, 표시하지 않으면 % 없이 움직이는 막대로 보입니다. Claude Code·Codex 모두 실행 중 공식 진행률을 주지 않아서 이 방식을 씁니다
- 왼쪽 작업 목록은 **확인 필요 → 실행 중 → 검토할 결과 → 끝남**으로 묶여 있고, 줄마다 지금 하는 일이나 내가 할 일이 한 줄 보입니다. ↑↓로 이동하고 Enter로 엽니다
- 작업을 누르면 AI가 알려 준 단계 목록(끝난 단계 ✓)과 AI가 쓴 글·사용한 도구가 실시간으로 보입니다
- 앱 창이 앞에 없을 때 작업이 끝나거나 실패하거나 한도에 닿으면 Windows 알림이 뜹니다
- 왼쪽 위 **사용량** 칸: Claude 5시간·7일, Codex 30일 사용률과 초기화 시각. 앱은 사용률을 직접 묻지 못해 마지막으로 받은 값을 보여 주며, "n시간 전 기준"으로 언제 값인지 표시합니다. 30분이 넘은 값은 막대가 흐리게 보이고, 새 작업 창에서 "실제는 더 높을 수 있음"을 알려 줍니다(아래 "사용률을 더 자주 받기" 참고)
- **다른 곳에서 연 세션**: Claude 데스크톱·VS Code·Codex 앱에서 직접 연 세션도 읽기 전용으로 보입니다(진행 중 여부 포함)

### 결과 확인과 정리

- 작업은 `<저장소 상위 폴더>\.tm-worktrees\<저장소 이름>\<작업 ID>`에서 `tm/<작업 ID>` 브랜치로 실행됩니다. 원래 저장소 폴더에는 바로 쓰지 않습니다
- 끝난 작업 상세에서는 **결과**가 맨 위에 있습니다. 바뀐 파일을 누르면 바뀐 줄이 색으로 보입니다(폴더를 열지 않고 검토)
- AI는 작업 폴더의 파일만 고치고 커밋하지 않습니다. [폴더 열기]로 결과를 확인하고, 결과 영역의 **원본 저장소에 반영하는 법**에 나온 세 줄(작업 폴더에서 커밋 → 원본에서 merge)을 터미널에서 실행하세요
- **이어서 지시**: 끝난 작업 상세 화면 아래 칸에 추가 지시를 적고 [보내기](Ctrl+Enter)를 누르면, 같은 대화와 같은 작업 폴더에서 이어집니다. 보낸 메시지는 기록에 "나:"로 남습니다
- 앱이 강제로 꺼져 AI 프로그램이 남아 있으면, 다음 실행 때 그 프로그램(claude·codex)만 찾아 끝내고 작업을 "앱 종료로 중단"으로 표시합니다
- [정리]는 작업 폴더와 브랜치를 지웁니다. 아직 합치지 않은 커밋이 있으면 지우지 않고, 커밋하지 않은 결과가 있으면 파일 개수를 보여 주고 한 번 더 묻습니다

### 한도와 요금 보호

| 상황 | 앱의 동작 |
|---|---|
| 사용률 80% 이상 | 새 작업 창에 경고 |
| 사용률 90% 이상 | 보내기를 막고 [직접 열기] 안내. 상의 모드는 그 AI를 빼고 진행 |
| 실행 중 구독 한도 도달 | 작업을 "한도 도달"로 멈춤. 초기화 뒤 [이어서 하기] |
| 추가 사용(유료 초과 사용)이 켜져 있음 | 사용량 칸과 새 작업 창에 경고 |
| Claude가 실행 중 추가 요금 구간에 들어감 | 즉시 멈추고 [직접 세션 열기] 안내 |
| `ANTHROPIC_API_KEY`·`OPENAI_API_KEY` 환경변수가 있음 | 구독 대신 종량제로 결제된다고 경고 |

**[터미널에서 직접 열기]** 는 새 터미널 창에서 공식 `claude`·`codex`를 대화형으로 엽니다. 작업 세션이 있으면 그 세션을 이어서 엽니다. 사용량·요금 설정을 직접 보면서 계속할지 정하세요.

### 사용률을 더 자주 받기 (선택)

Claude Code는 터미널에서 대화할 때마다 상태 표시줄 명령에 현재 5시간·7일 사용률을 넘겨줍니다. 저장소의 `scripts/usage-relay.cjs`를 그 명령으로 등록하면 그 값을 `~/.claude/agent-desk-usage.json`에 적고, agent-desk가 가장 최근 값으로 씁니다. 로그인 정보를 읽거나 네트워크를 쓰지 않습니다.

1. `scripts/usage-relay.cjs`를 `%USERPROFILE%\.claude\agent-desk-usage-relay.cjs`로 복사합니다
2. `%USERPROFILE%\.claude\settings.json`에 다음을 넣습니다(이미 `statusLine`이 있으면 바꾸게 되니 주의)
   ```json
   "statusLine": { "type": "command", "command": "node \"C:/Users/<사용자>/.claude/agent-desk-usage-relay.cjs\"" }
   ```

한계: 터미널의 `claude`에서만 동작합니다. Claude 데스크톱 앱은 상태 표시줄을 실행하지 않아 값이 들어오지 않습니다(2026-10-03 확인). 프로젝트 설정에 자기 `statusLine`이 있는 폴더에서도 동작하지 않습니다.

## 개발

```bash
npm install
npm start          # 개발 모드 실행
npm test           # 단위·통합 테스트(Vitest)
npm run typecheck
npm run dist       # 설치 파일 만들기 → release/
```

구조와 결정 근거는 [docs/design.md](docs/design.md), 실제 CLI 출력 형식은 [docs/cli-notes.md](docs/cli-notes.md)에 있습니다.

## 알려진 한계

- Windows 전용이고 설치 파일에 코드 서명이 없습니다
- 요금제·사용률·외부 세션은 각 도구가 PC에 남기는 파일을 읽습니다. 공개된 형식이 아니라서 도구가 업데이트되면 "확인 불가"로 보일 수 있습니다
- Claude 사용률은 실행 시작 때 들어오므로, 실행 도중에 %로 멈추지는 못합니다
- Codex는 실행 출력에 추가 요금 정보가 없어 실행 중 추가 요금 진입을 감지하지 못합니다(경고만 함)
- 진행 %는 AI가 스스로 알려 주는 단계 표시라 정확하지 않을 수 있습니다(2026-10-03 실제 실행에서 Claude·Codex 모두 표시함)
- 사용률은 마지막으로 받은 값이라 실제보다 낮을 수 있습니다. 정확한 값은 공식 도구의 `/usage`로 확인하세요
- Codex는 설치된 스킬이 너무 많으면 실행할 때마다 "Exceeded skills context budget" 오류 줄을 냅니다. 작업은 계속되며, 기록에 빨간 줄로 보입니다
